MOADMN



1\. Access court website

2\. Log in using public account credentials

3\. Go to matters

4\. Enter "25-" or "25-" on the filter field to view all dockets for the year 2025 and 2026

5\. Sort by Matter ID

6\. Open each matter ID and go to documents

7\. Search "order"

8\. Extract matter ID, document title, date created to a spreadsheet

9\. Compare the result to the sf-view/lndoc (filename) collected documents allowing 1week of before and 1 week after in date range comparison.

 	Ex. Matter ID - 12-3456, Doc Title - Order of Dismissal, Date Created - Nov 21, 2025

 		Compare result in sf view with matter id 12-3456 with possible decision date of Nov 14, 2025 - Nov 28, 2025

10\. If document is present in sf-view/lndoc, input "do not collect" *(Optional, depends on python capability)*

11\. If document was not collected, input in the spreadsheet "for collect" *(Optional, depends on python capability)*

12\. All documents inputted as for collect, copy the matter id and paste in on the filter located in all matters

13\. Click the link of the result

14\. Click documents

15\. Search "order"

16\. Look for 3 dots and click download

17\. For filenaming convention, use the matter id and date created
